# 致理基础难题与前沿领读调试 Prompt 集

这些 Prompt 延续“开发—冻结—迁移”的调试方式。参考答案、评分锚点和常见错误只在回答完成后交给裁判，不进入被测 Agent 上下文。

## P01 基础难题独立作答

你将收到一道基础学科高阶题。只声明与本题真正相关的前提维度，例如量词、数域、系统边界、近似尺度或算法模型；不要为凑模板罗列无关维度。随后完成证明、构造、计算、反例或条件性结论。题目条件充分时必须作答，不能用泛化的“信息不足”逃避。

## P02 第一处实质错误定位

把推导分成编号步骤。只定位第一处会改变结论的实质错误，说明该步违反的定理条件，并从此处给出最小修复；不要只说最终答案错了。

## P03 最小条件修复

若原命题不成立，优先给反例；若任务不是适合反例的逻辑命题，则给反机制、不可识别性构造或相互竞争的解释。再提出尽量弱且可核验的补充条件，并分别说明它为何充分、是否必要。

## P04 过度谨慎检查

复核答案是否在条件已经充分时仍拒绝推出结论。若能推出，请明确写出推理链；若不能，指出缺失的最小信息，而不是罗列所有可能风险。

## P05 结构对照

同时作答成对题：先写它们共享的表面词，再写真正不同的逻辑结构，最后分别选择方法。禁止把上一题的结论极性机械复制到下一题。

## P06 复合结构题

先把问题拆成两个相互作用的结构（例如测量效度+因果识别、系统边界+热力学判据），分别求解后再说明二者如何限制最终结论。

## P07 前沿领读主张—证据图

只根据给定的摘要转述，列出：方法产物、直接观测/基准结果、论文可支持主张、材料不能支持的更强主张。明确区分材料陈述、合理推断和自行扩展。

## P08 前沿领读边界反驳

面对“已经解决核心问题”的说法，给两条与该材料特异相关的边界。每条都要写明：受限对象、限制来自哪里、它阻止推出什么；泛泛的“还需研究”不计分。

## P09 可证伪后续实验

设计最小验证，必须包含对照、主要读出、预先定义的失败判据，以及它能区分或削弱的替代解释；只有在额外假设明确成立时才可写“排除”。实验结论的尺度不得超过实验本身。

## P10 开发失败归因

给定问题、回答、参考与原子评分锚点，把首错归为：知识缺口、结构误判、条件方向、跨层外推、证据不忠实、过度谨慎或表达遗漏。只有同类首错跨题重复时才建议修改通用规则。

## P11 冻结迁移裁判

规则已经冻结。按 required_claims、minimum_required_claims（若有）、required_inference_links、fatal_errors、overcautious_failure 和 minimum_boundary_statement 评分。被测 Agent 只接收 question 与 reading_brief；裁判只接收 question、reading_brief、source_claims、安全投影后的 rubric 与 answer。curator_inference、reported_evidence、known_unvalidated_links、reference、common_failures、structure_id 和 rule_target 均不得进入裁判请求。不得根据本题结果回写规则，只报告迁移表现和失败簇。

## P12 前沿领读任务条件化独立裁判

Task Router 必须在请求裁判前选择且只选择以下一套评分 Prompt，禁止把三套维度拼接后要求每题全部满足：

- A 类（概念解析）：检查概念定位、材料主张与回答推断的区分、关键推理箭头、前提和适用边界；不得因未写对照组而扣分。
- E 类（证据与边界）：检查比较对象、证据成熟度、数据切分或覆盖范围、校准、标度、部署接口、失败边界和结论强度；不得强行索要无关实验操作。
- B 类（实验设计）：检查可检验假设、对照或基线、干预、主要读出、预先失败判据和可区分的替代解释；不得因未写成概念综述而扣分。

每个被选维度按 0–2 分，并以题目 rubric 中的原子锚点决定通过门槛。伪造材料支持、把开放问题写成已证实，或触发 fatal_errors，直接判失败。路由标签只决定评分合同，不提供答案线索。

## P13 计算与构造题硬断言

带 hard_assertion schema 的题，回答须在自然语言推导后附一个机器可读块。代码先验证矩阵、轨迹、半正定性、曲线长度或绕数等确定性性质，再由模型裁判评价推理和边界。硬断言失败时最终 verdict 必须为 fail，语义裁判不得覆盖；硬断言通过也不自动代表论证完整。
