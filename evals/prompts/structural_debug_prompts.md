# 致理书院结构调试 Prompt 包 v2

这些 prompt 用于调试与评测，不把参考答案、常见失败或冻结题内容注入被测 Agent。

## P01 · 无规则基线

```text
【结构推理基线】
请独立回答下面的问题。给出可核验的关键推导和结论；条件不足或前提错误时必须明确指出。

题目：{question}
```

## P02 · 开发集结构训练

```text
【失败驱动开发模式】
先识别本题需要的推理操作，再给出可核验步骤与结论。检查必要/充分条件、系统边界和证据强度。信息不足时列出最小缺项并给条件分支；错误前提先纠错。

当前通用规则：
{rules}

题目：{question}
```

## P03 · 单题失败归因

```text
【失败归因】
只根据题目、Agent回答和独立裁判反馈分析失败，不接触冻结验证题。
输出：失败阶段（结构识别/前提检查/方法选择/推导/结论边界/表达）、最小错误点、诱发错误的表面线索、可复现反例、是否属于通用失败。

题目：{question}
Agent回答：{answer}
裁判反馈：{judge_feedback}
```

## P04 · 对照组失败比较

```text
【A–F 对照诊断】
比较同一结构组的回答。抽去领域名词，指出哪些变体发生了方法错配；尤其检查是否把上一题结论机械迁移到表面相似但条件不同的 B 题。

结构组记录：{group_rows}
```

## P05 · 通用规则归纳

```text
【规则归纳】
根据多个开发集失败提出一条最小通用规则。规则不得含题目专有名词或具体数值；必须采用：
“当可观察条件 A 成立时，使用方法 X；当条件 B 成立时，改用方法 Y；若关键条件未知，执行 Z。”
同时给出覆盖的失败ID、可能副作用和一个反例测试。

失败簇：{failure_cluster}
```

## P06 · 规则去过拟合审查

```text
【规则审查】
判断候选规则是否只是记住题面。检查：是否含专有实体；能否跨至少三个领域表述；是否错误扩大适用范围；是否会伤害已有通过题；是否可被明确反例推翻。

候选规则：{candidate_rule}
开发证据：{development_evidence}
```

## P07 · 纠错样本生成

```text
【纠错样本】
把失败转成一条纠错记录：原错误、错误原因、最小修正、抽象规则、修正后答案。不得把完整参考答案存入运行时记忆，只存抽象规则和失败标签。

失败：{failure}
```

## P08 · 回归测试选择

```text
【最小回归集】
根据本次规则变更，选择：直接失败题、同组相反条件题、至少两个跨领域同构题、一个此前通过且可能受副作用影响的题。解释每题为何入选。

规则差异：{rule_diff}
开发集索引：{development_index}
```

## P09 · 冻结迁移运行

```text
【冻结迁移验证】
规则版本已经冻结。独立回答题目，不查看训练示例、参考答案、常见失败或历史裁判反馈。输出关键步骤、条件与结论，不复述规则文本。

冻结规则：{rules}
题目：{question}
```

## P10 · 独立裁判

```text
【隔离裁判】
你只在回答完成后接收题目、参考要点和回答。分别评分：结构识别、前提检查、方法正确、关键推导、结论边界（各0-2）。指出首个实质错误；不得因文风、篇幅或与参考措辞不同而扣语义分。

题目：{question}
参考要点：{reference}
回答：{answer}
```

## P11 · 污染审计

```text
【污染审计】
检查规则、prompt、运行日志和代码改动中是否出现冻结题的专有短语、参考答案片段或ID。若出现，标记污染来源、受影响结构和需要降级为开发集的题。

冻结清单摘要：{holdout_fingerprints}
待审内容：{artifacts}
```

## P12 · 外部严格盲测出题

```text
【外部保管方盲测生成】
基于能力维度而非现有题面，生成从未展示给实现者的新题。至少一半采用新领域表面；包含缺条件、错误前提和证据不足；避免现有题的实体、数字和句法。保存题目与参考答案于实现者运行前不可见的位置，并在规则版本冻结后一次性释放评分结果。

能力维度：{capabilities_only}
数量：{count}
```

## P13 · 失败簇优先级

```text
【调试优先级】
按“影响结构数 × 严重度 × 可修复性”排序失败簇。不要按失败题数量直接排序，避免同一结构的重复题放大权重。

失败记录：{failures}
```

## P14 · 停止条件

```text
【迭代停止检查】
只有在开发回归通过、规则无新增特例、同结构冻结验证无明显退化、污染审计通过时才结束本轮。作者可见挑战只报告快照；没有外部盲测时明确写“尚未证明严格泛化”。

本轮记录：{iteration_report}
```
