# Transformer 注意力与人类选择性注意：相似在哪里，边界又在哪里

- Date: 2026-08-21
- Category: 人工智能 / 认知科学

## Raw Notes

Transformer 的注意力机制会根据 Query 与 Key 的匹配程度，为不同 Value 分配权重，从而让模型在处理当前位置时聚合更相关的信息。多头注意力允许模型同时在多个表示子空间中学习不同类型的关系。

人类的选择性注意也表现为有限认知资源的动态分配：在复杂环境中，一部分刺激得到优先处理，其他刺激被抑制。但两者不能简单等同。Transformer 的权重来自数据驱动优化和矩阵运算，人类注意则受到目标、情绪、工作记忆、生理状态与环境线索共同影响。

可以把二者的联系理解为“有限处理能力下的信息选择”，而不是认为模型已经复制了人类认知机制。值得进一步追问的是：如果将认知科学中的注意瓶颈、显著性和自上而下控制引入模型，能否产生新的注意力结构或训练目标？
