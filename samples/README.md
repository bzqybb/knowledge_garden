# 知识花园测试样例

这组样例用于验证“前沿追踪—知识定位—跨学科连接—Wiki 编译—用户审根”的完整流程。

## 样例一：SNN 前沿内容 → 教材—前沿对照卡

打开“前沿雷达”，复制 `01-SNN前沿材料.md` 中的标题、来源和正文。

预期结果：

- 提取出“脉冲神经网络”“代理梯度”“阶跃函数/反向传播”等概念
- 命中现有 Obsidian 中的 SNN 概念底座
- 生成“在你的知识树中的位置”“教材映射”“从教材到前沿”和思考题
- 产生回忆任务和小测任务
- 对照卡写入 Vault 的 `wiki/02-降维对照/`

## 样例二：摄影兴趣 → SNN 跨学科连接

打开“灵感温室”，输入：

- 标题：`高速摄影为什么要舍弃大部分时间` 
- 内容：复制 `02-摄影与脉冲编码.md`
- 标签：`摄影, 时间编码, 视觉`

预期结果：

- 兴趣碎片写入 `wiki/03-交叉火花/`
- 系统尝试连接到 SNN、离散脉冲或时间编码节点
- 显示隐喻、两条依据、置信度和苏格拉底追问
- Map 中出现珊瑚色兴趣节点和虚线候选连接
- 点击节点可以“接受/驳回”连接，操作后获得经验值

## 样例三：Raw → Wiki 自适应 Ingest

把 `03-Transformer注意力与选择性注意.md` 复制到 Obsidian Vault 的：

`raw/2026-08-21-transformer-selective-attention.md`

然后在“设置 → 编译 Raw 资料”输入：

`raw/2026-08-21-transformer-selective-attention.md`

预期结果：

- 在 `wiki/01-概念底座/` 创建缺失概念页
- 在 `wiki/02-降维对照/` 创建降维对照卡
- 每个核心概念都包含双向链接和苏格拉底追问
- 创建或更新主题 MOC
- 再次执行 Ingest 时不重复创建页面
- 链接检查结果为 0 个悬空链接

## 样例四：故意制造错误连接

在“灵感温室”输入：

- 标题：`咖啡杯的颜色与代理梯度`
- 内容：`我今天用了一个蓝色咖啡杯，因此想到蓝色可能会让代理梯度收敛得更快。`
- 标签：`咖啡, 颜色`

预期结果：

- 系统可能给出低置信度候选，或提示缺少可靠专业连接
- 若出现候选连接，证据不足应非常明显
- 用户可点击“驳回”，验证“AI 连接可质疑”机制

这个反例很适合答辩：它证明系统没有把知识图谱中的每条 AI 联想都当成事实。

## 样例五：重复同步与幂等性

连续两次点击“保存并同步 Obsidian”。

预期结果：

- 第一次显示扫描和更新数量
- 第二次扫描数量不变，更新数量应接近或等于 0
- Map 不应生成重复节点
- 原有 Obsidian 页面内容不应被覆盖
