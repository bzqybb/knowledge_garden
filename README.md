# Knowledge Garden: LLM Wiki 通用知识编译器与导师智能体

基于 `AGENTS.md` 规则驱动的离线/在线自适应知识编译系统。智能体（Agent）负责将 `raw/` 目录中的原始碎片资料（论文、笔记、思考）自动解构、提炼，并编译为互联的 `wiki/` 数字花园网络，同时提供克制的苏格拉底式启发引导。

---

## 🛠️ 目录架构与流向

```text
llm-wiki-lab/
├── AGENTS.md                  # 智能体核心行为准则与编译 Prompt
├── raw/                       # 👥 原始输入区：剪藏论文、个人笔记、思考碎片
└── wiki/                      # 🧠 编译输出区：结构化知识资产
    ├── 01-概念底座/           # 核心名词、定理定义与基础理论
    ├── 02-降维对照/           # 复杂案例/工程应用与底层原理的映射
    ├── 03-交叉火花/           # 仅在产生自主思考时触发的跨界推导
    └── 04-主题索引/           # MOC (Map of Content) 动态思维导图树

```

---

## 🚀 智能体核心功能

* **客观增量编译（克制建树）**
* **不盲目联想**：智能体在处理单篇资料时，仅围绕当前文本提炼核心概念，拒绝无依据的强行跨界。
* **知识树挂载**：自动提取专有名词存入 `01-概念底座/`，并精准挂载到 `04-主题索引/` 的 MOC 树枝上，形成清晰的知识 Mindmap。


* **严谨自然的双向链接（`[[双链]]`）**
* 仅在概念间存在明确学术、逻辑或定理依赖时自动补全 `[[双向链接]]`。
* 对于未建页面的衍生概念，自动生成初始占位卡片，保证知识图谱生长的连贯性。


* **单点聚焦的苏格拉底追问**
* 拒绝泛泛而谈，在编译出的卡片末尾，针对该概念自身的**底层推导、边界条件或失效场景**，留下 1~2 个具有启发性的思考题，辅助吃透基础。


* **用户直觉驱动的“交叉火花”（写回机制）**
* **触发条件**：仅当在 `raw/` 笔记中检测到【用户个人备注/直觉思考】（如：“我觉得这个算法和某个心理学效应很像”）时，智能体才会顺着用户的灵感脉络展开深入推导。
* **资产写回**：将深入碰撞的成果格式化整理写入 `03-交叉火花/`，并双向链接回相关的概念底座。


* **Git 多人/多端共创友好**
* 天然契合 GitHub 与 Obsidian 纯文本工作流，支持团队按目录（如 `raw/user_a/`）异步提交原始资料，通过统一的 `AGENTS.md` 标准实现 Wiki 编译资产的无缝合并与同步。

## 📖 交互使用流程

1. **投递资料**：将任意 Markdown 笔记或论文摘要放入 `raw/` 目录。
2. **触发编译**：在 Codex / Agent 终端中运行指令：
```text
请按照 AGENTS.md 的规则对 raw/新增文件.md 执行自适应 Ingest。

```


3. **图谱复盘**：打开 Obsidian 按 `Ctrl + G`（Mac: `Cmd + G`），在关系图谱中查看新概念如何自然融入已有知识网。
