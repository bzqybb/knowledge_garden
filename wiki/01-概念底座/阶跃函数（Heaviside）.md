# 阶跃函数（Heaviside）

**阶跃函数**（Heaviside step function）是[[脉冲神经网络（SNN）]]中模拟神经元脉冲发放的最简模型：膜电位超过阈值输出 1，否则输出 0。

## 数学特性

```
H(x) = 1  if x ≥ 0
     = 0  if x < 0
```

- 阈值处（x = 0）：导数未定义 / 视为无穷大
- 其余位置：导数为 0

## 为何阻碍训练

[[反向传播（Backpropagation）]]依赖链式法则逐层传递梯度。阶跃函数几乎处处梯度为零，阈值点不可微，导致梯度无法穿过发放节点——这是 SNN 训练面临「不可微 / 梯度消失」问题的根源。

## 常见应对

在前向传播保留阶跃函数离散行为，反向传播时用连续可微的替代导数——即[[代理梯度（Surrogate Gradient）]]。完整映射见[[SNN 训练中的代理梯度]]。
