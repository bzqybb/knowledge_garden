# 内置第三方组件

正式 Windows 安装包设计为一次安装完成，不要求用户另行下载插件。

| 组件 | 用途 | 固定方式 | 发布约束 |
|---|---|---|---|
| TraceMemo v2.2.3 | 本机微信只读数据桥接 | 内置官方 Windows x64 安装器 + GitHub 资产 SHA-256 | 仅限比赛、测试和非商业展示；主安装器自动静默安装，商业化前必须取得书面许可 |
| `@xzxzzx/bilibili-mcp` 1.13.1 | 登录态字幕、转录和视频工具 | npm 精确版本 + 随包 GPL-3.0 LICENSE | 保留许可证、版本与上游来源 |
| Node.js | 运行 Bilibili MCP | CI 中当前 Node 22 可执行文件 | 保留对应 Node.js 第三方许可清单 |

“内置”只表示程序文件随安装包分发。微信数据库访问与 B 站账号登录仍需由用户本人在首次使用时明确授权。公测模型凭据只保存在知识花园服务器；安装包不包含 API Key，用户桌面端只保存自己的加密会话令牌。
